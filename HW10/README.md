# HW10 — Тестові фреймворки. Написання юніт-тестів

## Завдання

1. Рекомендовано самостійно розібратися з тестовим фреймворком Jasmine, Vitest (документація).

2. Взяти за основу ДЗ із заняття 9 (або за відсутності з 8). 

3. Покрити юніт-тестами методи класу за допомогою Mocha (методи класу які вертають не void).
 
4. Перевірити юніт-тестами функції, які маніпулюють об’єктами (вхідніпараметри в функції) за допомогою Jest або Vitest (index.ts з лекції 8 або 9)
 
5. Асершени мають бути як з тестового фреймворку (якщо є), так і з Chai.

## Як запустити

### Вимоги
- [Node.js](https://nodejs.org/) v22+

### Встановлення залежностей
```bash
cd mocha-chai
npm install
```

```bash
cd vitest
npm install
```

### Запуск файлів
```bash
cd mocha-chai
npx tsx ./src/index.ts
```

```bash
cd vitest
npx tsx ./src/index.ts
```

### Запуск тестів
```bash
cd mocha-chai
npm test
```

```bash
cd vitest
npm test
```
