# HW14 — Воркшоп: створення власного фреймворку для API тестування

## Завдання

### Написати свій перший проєкт для API-тестування:

1. Обрати за основу базовий тестовий фреймворк на власний розсуд (Mocha, Jest, Vitest, Jasmine)

2. Вибрати утиліту для роботи з запитами (fetch, axios, request, APIRequestContext) та створити сервіс для їх обробки 

3. Взявши за основу домашнє завдання до лекції 12 або 13 описати запити в API Objects
 
4. Написати 5 API тестів

## Як запустити

### Вимоги
- [Node.js](https://nodejs.org/) v22+

### Встановлення залежностей
```bash
npm install
```

### Запуск тестів
```bash
npm test
```
