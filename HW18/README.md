# HW18 — Playwright як E2E Web UI фреймворк для тестування

## Завдання

1. Ознайомитися з документацією Playwright.

2. Створити Playwrigh Test проєкт. Обрати будь-яку сторінку в інтернеті та описати її в Page Model. Зробити кілька тестів для цієї сторінки (не менше 3х).
 
3. Ознайомитися з документацією, як працювати із Shadow DOM та iFrame. Ознайомитися з Playwright Fixtrures
