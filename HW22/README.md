# HW22 — CI/CD у автоматизованому тестуванні

## Завдання

1. Створити на попередні домашні пайплайни для автоматичного запуску тестів на GitHub Actions (на домашки до лекцій по Playwright та WDIO) та вивантажувати результати тестування.

2. Ознайомитися з поняттям Kubernetes.


### Запуск тестів

npm run test:headed
