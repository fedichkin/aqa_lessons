# HW4 — Цикли. Масиви та об'єкти

## Завдання

1. Створити проєкт JS.

2. Сформувати файл **`loop.js`**, у якому створити по одному циклу проходу від 0 до 9, на кожній ітерації якого виводитиметься значення поточного ітератора. Потім по одному циклу від 100 до 0 з кроком 10, де виводитиметься ітератор на кожній ітерації. (по одному => for, while, do..while)

3. Підготувати файл **`arrays.js`**, у якому додати 4 масиви, по 1 на кожен базовий тип (рядок, число, boolean, any), та виконати вивчені операції (reduce, sort, filter, find, indexOf, concat, groupBy) над ними включно з перебором (forEach() та map()).

4. Створити файл **`objects.js`**, у якому зробити комплексний об’єкт, що мав би мінімум 2 рівні ієрархії, масив та метод, який виводитиме значення.

## Як запустити

### Вимоги
- [Node.js](https://nodejs.org/) v22+

### Встановлення залежностей
```bash
npm install
```

### Запуск файлів
```bash
node src/loop.js
node src/arrays.js
node src/objects.js
```
